# Campus Lost & Found

A full-stack web application designed to help students report, search, and recover lost and found items on campus.

## 🚀 Features

- User Registration & Login
- Report Lost Items
- Report Found Items
- Item Image Upload
- Search and Filter Reports
- Item Details Page
- Claim Request System
- Duplicate Claim Protection
- Admin Approve / Reject Claims
- User Dashboard
- My Reports
- My Claims
- Background Video Hero Section

## 🛠️ Tech Stack

- Python
- Django
- SQLite
- HTML
- CSS
- Django Templates

⚙️ Run Locally

Clone the repository:
git clone https://github.com/sohaib4923/campus-lost-found.git
cd campus-lost-found

Create and activate a virtual environment:
python -m venv venv

Windows:
venv\Scripts\activate

Install dependencies:

pip install django pillow

Run migrations:

python manage.py migrate

Start the development server:

python manage.py runserver 8000

Open:

http://127.0.0.1:8000/

The goal of this project is to provide a simple digital platform for college students to report lost or found belongings and make the recovery process easier.
